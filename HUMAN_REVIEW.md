# Human review checklist — external demo

Items that should be spot-checked by a human before any public/interview share.
Runtime gates and the 3-minute path live in [`INTERVIEW_HANDOFF.md`](INTERVIEW_HANDOFF.md).

1. **Competitive cards** — after Relay reframe, any line that still feels employer-derived or overly aggressive
2. **Account briefs** — accuracy of “public observation” vs hypothesis; source labels
3. **Finance / TCO tone** in personas and comps — avoid sounding like private deal strategy
4. **Turso** — confirm a dedicated **demo** database (not the private hub DB) before `npm run seed`
5. **Never merge** this branch into private `main`; public share only via orphan export (README)
6. **Call Analysis** — only use synthetic or consented transcripts in live demos
7. **History** — do not push this branch’s full git history to a public remote (private ancestors remain reachable)
