# Human review checklist

Items to spot-check before an external walkthrough. Runtime commands and the 3-minute path live in [`INTERVIEW_HANDOFF.md`](INTERVIEW_HANDOFF.md).

1. **Competitive cards** — any line that feels too aggressive or unsupported by public research
2. **Account briefs** — accuracy of “public observation” vs hypothesis; source labels
3. **Finance / TCO tone** in personas and comps — keep it educational, not deal-strategy theatre
4. **Turso** — confirm you are seeding your own database before `npm run seed`
5. **Call Analysis** — only use synthetic or consented transcripts in live demos
6. **Secrets** — no `.env.local` committed; only `.env.local.example` with placeholders
