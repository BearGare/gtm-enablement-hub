# Demo script — GTM Signal Hub (≈3 minutes)

Audience: GTM / SDR leadership at a developer-tools or AI company.

## Why this hub exists

A working system that forces the same discipline used on accounts: map the value stream, pick the persona, separate public signal from hypothesis, then earn the right to an outbound angle — with AI as a coach, not a content spitballer.

## Tab map (exact labels)

`Dashboard` · `Solutions` · `SDLC` · `Personas` · `Accounts` · `Competitive` · `Outbound` · `Discovery` · `Glossary` · `Calls` · `Methodology` · `Progress` · `Settings`

## 3-minute path

### 0:00–0:20 — Dashboard
Open **Dashboard**. One sentence: “This is how I organise market → account → play.” Point at Solutions / Accounts / Personas / Battlecards counts. Click **Explore SDLC Map**.

### 0:20–1:20 — SDLC (centrepiece)
Walk the **value stream**: Plan → Code → Build → Test → Secure → Release → Operate → Improve.  
Open **Release** or **Test**. Show enterprise problems, persona relevance, Relay module fit, outbound hooks. Optional: **Coach me on Release →**.  
Punchline: Relay can cover the whole stream — but we start where work is waiting.

### 1:20–2:00 — Account brief
Open **Accounts** → e.g. Cloudflare or Stripe.  
Show **public signals** vs **labelled hypotheses**. Point at module fit + next best action.  
Explicitly say: “I will not invent private knowledge in a live account.”

### 2:00–2:50 — Outbound Lab (wow)
**Outbound** (page title: Outbound Lab) → select that account + **VP Engineering** + **Release** (or **Code**) + tone.  
Click **Generate Openers** → email / LinkedIn / call openers + **AI Coach Notes**.  
Optional: **Polish with AI** (needs `ANTHROPIC_API_KEY`).  
Optional: open **Competitive** → **⭐ Top** for 15s.

### 2:50–3:10 — Methodology
Open **Methodology**. State the boundary: public vs hypothesis, Relay is fictional, AI outputs need review.

### Optional (+1 min)
**Calls** → **Load sample transcript** → **Analyse Call**.
