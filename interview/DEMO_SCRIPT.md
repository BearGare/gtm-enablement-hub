# Demo script — GTM Enablement Hub (≈3 minutes)

Audience: GTM / SDR leadership at a developer-tools or AI company.

## Why this hub exists

A working system that forces constraint-first discipline: map the value stream, confirm the wedge, practise discovery and objections — with AI as a coach, not a content spitballer. Built for the complexity of selling a multi-module delivery platform.

## Tab map (exact labels)

`Dashboard` · `Solutions` · `SDLC` · `Personas` · `Competitive` · `Discovery` · `Land Planner` · `Objection Gym` · `Glossary` · `Calls` · `Progress` · `Settings`

## 3-minute path

### 0:00–0:20 — Dashboard
Open **Dashboard**. One sentence: “Market → constraint → land → practice.” Click **Explore SDLC Map**.

### 0:20–1:00 — SDLC
Walk Plan → Improve. Open **Release** (or **Test**). Punchline: start where work waits.

### 1:00–1:40 — Discovery Paths
**Discovery** → **Path** mode → pick that stage → walk 2–3 steps → **Open Land Planner**.

### 1:40–2:20 — Land Planner
Show wedge module, toolchain honesty (coexist vs replace), proof ladder. **Copy land brief**.

### 2:20–2:55 — Objection Gym
Filter **category reframe** → open “So you're like GitLab…” → show trap + strong answer → optional **Practice with AI**.

### Optional (+1 min)
**Calls** → **Load sample transcript** → **Analyse Call**. Or **Settings → About this hub**.
